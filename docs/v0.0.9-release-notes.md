# v0.0.9 更新说明

- 增强独立 Kotlin/JVM `archive-core` 的 ZIP 边界：单条目读取支持大小限制、取消检查和进度回调。
- 解压会拒绝目标目录中的符号链接，并在提交前检测输出父路径冲突，避免跟随链接写出目标目录。
- 增加重复规范化路径、条目数量、读取取消/进度、输出父路径冲突和符号链接回归测试。
- Android `ArchiveRepository`、RAR/7z/TAR/Zstandard 迁移和桌面 GUI/TUI/CLI 仍按 `NEXT_PLAN.md` 分阶段推进；本版本不宣称桌面平台已支持。
- Release workflow 继续生成四种 ABI APK、`mapping.txt`、SHA-256 和发布元数据；不生成 AAB，不新增云盘功能。

验证记录：远端 Ubuntu x86_64、JDK 17 和 Android SDK 环境已通过 `:archive-core:test`、`test` 与 `lintRelease`。
