# v0.0.11 更新说明

## 发布摘要

`v0.0.11` 完成独立 Zstandard `.zst` 的第一阶段 `archive-core` 迁移。Android 继续保留 SAF、缓存、权限和系统 chooser 适配，单流解压、读取上限、取消、损坏归类和事务式输出由 Kotlin/JVM 核心负责。

版本元数据：`versionCode 13`、`versionName 0.0.11`。

## 具体变更

### 独立 Zstandard 核心迁移

- 新增 `ZstandardArchiveCore`，支持独立 `.zst` 的展开大小测量、受限读取、流式复制和事务式文件解压。
- 核心统一执行最大展开体积、调用方读取上限、取消、损坏流分类、输出冲突和符号链接父路径检查。
- 事务式文件解压先写同目录随机 `.part` 文件，成功后再替换目标；失败和取消会清理临时文件。

### Android 接入

- Android `.zst` 列表、解压、预览、内部存储解压和外部打开改为调用 `ZstandardArchiveCore`。
- SAF URI 暂存、`DocumentFile` 目标写入、覆盖策略、chooser 和进度桥接继续留在 Android 适配层。
- 保留 `v0.0.9-fix2` 的单文件 SAF URI 分流，不新增 `MANAGE_EXTERNAL_STORAGE`。

## 测试与发布门禁

- 新增单流测量、读取、复制、事务解压、上限、损坏分类、取消清理、源覆盖和符号链接父路径测试。
- Release workflow 执行 `:archive-core:test`、Android `test`、`lintRelease`、四 ABI 签名 APK 构建、证书校验、SHA-256 和发布元数据归档。
- Termux 本机缺少 glibc 兼容的 `libpthread.so.0`，Zstandard 原生闭环测试按既有策略跳过；完整 Android 门禁以 GitHub Actions 结果为准。

## 不在本版本范围内

- RAR/RAR5、7z 核心迁移和 RAR 创建。
- ZIP/TAR/Zstandard 密码加密、桌面 GUI/TUI/CLI、Windows/Linux/macOS 原生打包和桌面云端功能。
