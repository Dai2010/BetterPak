# v0.0.5 格式验收

## 范围

v0.0.5 增加以下能力：

- TAR：识别、目录浏览、创建、受限解压和受限预览。
- Zstandard：识别 `.zst` 单流，显示一个元数据条目，支持受限解压和受限内容预览；不伪装成目录归档。
- TAR + Zstandard：识别 `.tar.zst`/`.tzst`，目录浏览、创建、受限解压和受限预览。
- 所有新格式都拒绝密码输入；TAR 特殊条目、绝对路径、路径穿越和 NUL 路径不会写入目标目录。

## 本地互操作样本

样本必须在临时目录中生成，脚本退出后清理；不要提交样本或私人密码：

```sh
tmp_dir="$(mktemp -d)"
trap 'rm -rf "$tmp_dir"' EXIT
mkdir -p "$tmp_dir/source/中文目录/空目录"
printf 'hello\n' > "$tmp_dir/source/中文目录/readme.txt"
: > "$tmp_dir/source/零字节.bin"
tar -cf "$tmp_dir/sample.tar" -C "$tmp_dir/source" .
zstd -q -f "$tmp_dir/sample.tar" -o "$tmp_dir/sample.tar.zst"
printf 'single stream\n' | zstd -q -f -o "$tmp_dir/single.txt.zst"
tar -tf "$tmp_dir/sample.tar" >/dev/null
tar -tf "$tmp_dir/sample.tar.zst" >/dev/null
zstd -q -t "$tmp_dir/single.txt.zst"
```

损坏帧、错误校验和超限展开应由 Android 引擎返回失败，且不得留下 `.part` 文件或不完整目标文件。取消测试应在大于预览/解压限制的样本上执行，并检查临时文件清理。

## Android/CI 验收矩阵

以下命令必须在具备 Android SDK 的 CI 或开发机执行：

```sh
gradle --no-daemon --max-workers=1 test lintRelease
gradle --no-daemon --max-workers=1 assembleRelease
```

| 项目 | 环境/样本 | 结果 | 记录位置 |
| --- | --- | --- | --- |
| `test` | CI 运行编号 | 待设备/CI 执行 | CI 日志 |
| `lintRelease` | CI 运行编号 | 待设备/CI 执行 | CI 日志 |
| TAR UTF-8、目录、空文件 | 固定哈希样本 | 待真机执行 | `docs/` 验收记录 |
| `.zst` 单流预览/解压 | 固定哈希样本 | 待真机执行 | `docs/` 验收记录 |
| `.tar.zst` 浏览/预览/解压 | 固定哈希样本 | 待真机执行 | `docs/` 验收记录 |
| 穿越、特殊条目、超限、取消 | 本地生成恶意样本 | 待真机执行 | `docs/` 验收记录 |

记录时至少填写真机型号、Android 版本、APK 文件名和 SHA-256、样本 SHA-256、操作结果和已知限制；不得保存私人样本或聊天中的密码。

## 已知限制

- TAR/Zstandard 不提供标准密码能力，界面不会显示密码输入。
- 独立 `.zst` 只有一个解压后的文件条目，没有目录列表。
- 软链接、硬链接、设备文件、FIFO 和其他 TAR 特殊条目会被拒绝，而不是还原到用户目录。
- 当前 Termux 工作区没有 Java、Gradle 或 Android SDK，不能在本机宣称 Android 单元测试、APK 构建或真机互操作通过。
